# CLAUDE.md

## Repository scope (hard rule)

This repository, `UselessSilicon/wifi-shuriken`, is a fork. The upstream
project belongs to CoD_Segfault.

- NEVER push, merge, open pull requests, or post comments or reviews against
  the upstream (CoD_Segfault) repository.
- All work goes to this fork only: its branches, its `main`, and pull requests
  whose base and head are both in `UselessSilicon/wifi-shuriken`.
- Pulling upstream changes *into* this fork is allowed when asked. Nothing is
  ever sent back upstream.
- Before creating a pull request, confirm that its base repository is
  `UselessSilicon/wifi-shuriken`.
