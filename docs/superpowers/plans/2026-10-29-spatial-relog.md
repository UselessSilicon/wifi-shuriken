**Goal:** Re-log an access point when the device has moved >= 25 m or the signal is >= 6 dB stronger since that AP's last row, on by default, with 0/0 restoring today's output exactly.

**Architecture:** The two identity dedupe tables (scanner and controller core1) gain a time-to-live so repeats reach core0. A new pure gate module in `lib/wifi_common` decides on core0, inside `Logger::appendCsvRow`, whether a repeat becomes a CSV row, using the same GPS fix the row uses. No SPI protocol or CSV format change.

**Tech Stack:** C++ (Arduino-Pico on RP2350, Arduino-ESP32 on ESP32-C5), PlatformIO, Unity native tests, xxHash.

**Spec:** `docs/superpowers/specs/2026-10-29-spatial-relog-design.md`

1. Parked device with fluctuating RSSI (for example -80..-70 dBm noise at one spot): rows must stay bounded, not grow with time. Test `test_relogGate_stationary_rssi_noise_bounded` in Task 3.
2. Fix lost then a positionless repeat: must be suppressed (no blank-coordinate spam), and the old position kept so the next positioned sighting is measured from it. Test `test_relogGate_positionless_repeat_after_fix_suppressed` in Task 3.

### Task 3: Spatial re-log gate module

**Files:**
- Create: `lib/wifi_common/wifi_relog_gate.h`, `lib/wifi_common/wifi_relog_gate.cpp`
- Test: `test/test_wifi_common/test_main.cpp`

**Interfaces:**
- Consumes: `WiFiDedupeHash`, `wifiDedupeHashEquals`, `wifiDedupeHashFromFields` (Task 2).
- Produces:

```cpp
struct RelogGateEntry { WiFiDedupeHash key; int32_t lat_e7; int32_t lon_e7; int8_t rssi; uint8_t has_pos; };
struct RelogGate {
  RelogGateEntry* entries;   // ring in insertion order, capacity entries
  uint16_t* slots;           // open addressing over entry indices; 0xFFFF = empty
  uint16_t table_size;       // power of two, >= 2 * capacity
  uint16_t capacity;         // < 0xFFFF
  uint16_t count;
  uint16_t head;             // oldest entry index
};
struct RelogGateConfig { uint16_t distance_m; uint8_t rssi_gain_db; };
enum class RelogDecision : uint8_t { LogFirstSight, LogFixArrived, LogMoved, LogStronger, Suppress };

void relogGateInit(RelogGate* gate, RelogGateEntry* entries, uint16_t capacity, uint16_t* slots, uint16_t table_size);
void relogGateReset(RelogGate* gate);
RelogDecision relogGateDecide(RelogGate* gate, const WiFiDedupeHash& key, bool has_pos,
                              int32_t lat_e7, int32_t lon_e7, int8_t rssi, const RelogGateConfig& cfg);
```

Decision order for a known key (spec section 3):
1. If `distance_m == 0 && rssi_gain_db == 0`, return Suppress.
2. If `has_pos && !entry.has_pos`, return LogFixArrived.
3. If `has_pos && entry.has_pos && distance_m > 0` and the distance is at least `distance_m`, return LogMoved.
4. If `has_pos && rssi_gain_db > 0 && (int16_t)rssi >= (int16_t)entry.rssi + rssi_gain_db`, return LogStronger.
5. Otherwise return Suppress.

An unknown key returns LogFirstSight and is inserted. When full, evict `entries[head]` (backward-shift delete its slot), reuse that index, and advance head.

On every Log*, store `has_pos`, `lat_e7`, `lon_e7` and `rssi`. On Suppress, change nothing.

Distance uses this algorithm, which the signature does not determine:

```text
dlat_deg = (lat_e7 - stored_lat_e7) * 1e-7
dlon_e7  = (int64)lon_e7 - stored_lon_e7;  if dlon_e7 > 1.8e9: dlon_e7 -= 3.6e9;  if < -1.8e9: += 3.6e9
dx = dlon_e7 * 1e-7 * cosf(stored_lat_deg) * 111320.0f;  dy = dlat_deg * 111320.0f
moved = dx*dx + dy*dy >= (float)distance_m * distance_m
```
